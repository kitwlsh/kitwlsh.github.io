# kitwlsh.github.io

K-시리즈 앱의 **도메인 루트 파일** 자리. 이 저장소는 그 목적만 가진다.

| 파일 | 왜 여기에 |
|---|---|
| `app-ads.txt` | AdMob 판매자 인증. Play에 등록한 개발자 웹사이트(`https://kitwlsh.github.io/k-series-config/`)에서 **경로를 뗀 루트**(`https://kitwlsh.github.io/app-ads.txt`)만 크롤링된다 — 그래서 `k-series-config`에 두면 인식되지 않는다 |

- 🔑 게시자 ID 하나에 한 줄. 광고를 넣는 K-시리즈 앱이 늘어도 **이 줄을 그대로** 공유한다
- 🔴 게시자 ID가 바뀌면(계정 이전 등) 이 파일도 함께 고친다
- 개인정보 처리방침·`family.json`은 여기가 아니라 `k-series-config`에 있다
